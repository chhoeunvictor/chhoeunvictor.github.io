Introduction

Flowdesk API

The Flowdesk API lets you integrate Flowdesk's workspace, page, and notification features directly into your own applications. Use it to automate content creation, sync data across tools, or build custom workflows for your team.

All API requests are made over HTTPS and return JSON. The base URL for all endpoints is:

Base URL
https://api.flowdesk.io/v1
ℹ

This is a sample API reference created as a portfolio writing sample. Flowdesk is a fictional product. All endpoints, data, and examples are illustrative.

Authentication

Authenticating requests

Flowdesk uses API keys to authenticate requests. You can generate and manage your API keys from your workspace's Settings → Developer page.

Include your API key in the Authorization header of every request using the Bearer scheme.

Example request header
Authorization: Bearer fd_live_a1B2c3D4e5F6g7H8i9J0
⚠

Keep your API key secret. Do not expose it in client-side code, public repositories, or anywhere it could be accessed by others. Rotate your key immediately if it is compromised.

API key types

Type Prefix Description
Live key fd_live_ For production use. Actions performed with this key are real and permanent.
Test key fd_test_ For development and testing. All data is sandboxed and will not affect your live workspace.
Pages

Pages

Pages are the core content unit in Flowdesk. A page belongs to a workspace and can contain rich text, embedded media, and nested sub-pages. Use these endpoints to create, retrieve, update, and delete pages programmatically.

GET /pages List all pages in a workspace ▼

Query parameters

ParameterTypeRequiredDescription
workspace_id string required The unique ID of the workspace to retrieve pages from.
limit integer optional Number of pages to return. Defaults to 20. Max is 100.
cursor string optional Pagination cursor returned by a previous request. Used to retrieve the next page of results.
archived boolean optional If true, returns only archived pages. Defaults to false.

Example request

cURL
curl -X GET \ "https://api.flowdesk.io/v1/pages?workspace_id=ws_abc123&limit=10" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6"

Response

200 OK 401 Unauthorized
JSON
{ "object": "list", "results": [ { "id": "pg_7xK2mNpQ", "object": "page", "title": "Product Roadmap Q3", "created_at": "2024-08-01T09:14:00Z", "updated_at": "2024-08-12T16:45:00Z", "archived": false, "created_by": "usr_9aR3bTcU" } ], "next_cursor": "crs_mX4nYpZ8", "has_more": true }
JSON
{ "error": { "code": "unauthorized", "message": "Invalid or missing API key." } }
POST /pages Create a new page ▼

Request body

ParameterTypeRequiredDescription
workspace_id string required The ID of the workspace where the page will be created.
title string required The title of the new page. Max 255 characters.
content string optional Initial body content for the page in Markdown format.
parent_id string optional The ID of a parent page. If provided, the new page is created as a sub-page.

Example request

cURL
curl -X POST \ "https://api.flowdesk.io/v1/pages" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6" \ -H "Content-Type: application/json" \ -d '{ "workspace_id": "ws_abc123", "title": "Meeting Notes — August", "content": "## Agenda\n- Q3 review\n- Roadmap planning" }'

Response

201 Created 400 Bad Request
JSON
{ "id": "pg_3wL8nRpT", "object": "page", "title": "Meeting Notes — August", "content": "## Agenda\n- Q3 review\n- Roadmap planning", "workspace_id": "ws_abc123", "parent_id": null, "archived": false, "created_at": "2024-08-14T11:02:33Z", "created_by": "usr_9aR3bTcU" }
JSON
{ "error": { "code": "invalid_request", "message": "The 'title' field is required.", "param": "title" } }
PUT /pages/{page_id} Update an existing page ▼

Path parameters

ParameterTypeRequiredDescription
page_id string required The unique ID of the page to update.

Request body

ParameterTypeRequiredDescription
title string optional New title for the page. Max 255 characters.
content string optional Updated body content in Markdown format. Replaces all existing content.
archived boolean optional Set to true to archive the page. Archived pages are hidden but not deleted.

Example request

cURL
curl -X PUT \ "https://api.flowdesk.io/v1/pages/pg_7xK2mNpQ" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6" \ -H "Content-Type: application/json" \ -d '{ "title": "Product Roadmap Q3 — Updated", "content": "## Q3 Goals\n- Launch feature A\n- Ship v2" }'

Response

200 OK 404 Not Found
JSON
{ "id": "pg_7xK2mNpQ", "object": "page", "title": "Product Roadmap Q3 — Updated", "content": "## Q3 Goals\n- Launch feature A\n- Ship v2", "workspace_id": "ws_abc123", "archived": false, "updated_at": "2024-08-15T09:30:00Z" }
JSON
{ "error": { "code": "not_found", "message": "No page found with the ID 'pg_7xK2mNpQ'." } }
DEL /pages/{page_id} Permanently delete a page ▼

Path parameters

ParameterTypeRequiredDescription
page_id string required The unique ID of the page to delete. This action is permanent and cannot be undone.
⚠

Deleting a page is permanent. All sub-pages nested under it will also be deleted. To hide a page without deleting it, use the archived field in the Update page endpoint instead.

Example request

cURL
curl -X DELETE \ "https://api.flowdesk.io/v1/pages/pg_7xK2mNpQ" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6"

Response

200 OK 404 Not Found
JSON
{ "object": "page", "id": "pg_7xK2mNpQ", "deleted": true }
JSON
{ "error": { "code": "not_found", "message": "No page found with the ID 'pg_7xK2mNpQ'." } }
Workspaces

Workspaces

A workspace is the top-level container in Flowdesk — it holds all pages, members, and settings for a team. Use these endpoints to retrieve workspace details and list members.

GET /workspaces/{workspace_id} Retrieve a workspace by ID ▼

Path parameters

ParameterTypeRequiredDescription
workspace_id string required The unique ID of the workspace to retrieve.

Example request

cURL
curl -X GET \ "https://api.flowdesk.io/v1/workspaces/ws_abc123" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6"

Response

200 OK 404 Not Found
JSON
{ "id": "ws_abc123", "object": "workspace", "name": "Acme Team", "domain": "acme", "plan": "pro", "member_count": 12, "created_at": "2023-03-10T08:00:00Z" }
JSON
{ "error": { "code": "not_found", "message": "No workspace found with the ID 'ws_abc123'." } }
GET /workspaces/{workspace_id}/members List all members of a workspace ▼

Path parameters

ParameterTypeRequiredDescription
workspace_id string required The unique ID of the workspace.

Query parameters

ParameterTypeRequiredDescription
role string optional Filter by role. One of owner, admin, or member.
limit integer optional Number of members to return. Defaults to 20. Max is 100.

Example request

cURL
curl -X GET \ "https://api.flowdesk.io/v1/workspaces/ws_abc123/members?role=admin" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6"

Response

200 OK 401 Unauthorized
JSON
{ "object": "list", "results": [ { "id": "usr_9aR3bTcU", "object": "member", "name": "Jamie Lee", "email": "jamie@acme.com", "role": "admin", "joined_at": "2023-04-01T10:00:00Z" } ], "has_more": false }
JSON
{ "error": { "code": "unauthorized", "message": "Invalid or missing API key." } }
Notifications

Notifications

Use the Notifications API to send in-app alerts to workspace members — for example, notifying a team when a page is updated, a task is assigned, or an external event occurs.

POST /notifications Send a notification to one or more users ▼

Request body

ParameterTypeRequiredDescription
recipient_ids array required An array of user IDs to send the notification to. Max 50 recipients per request.
message string required The notification message body. Max 500 characters. Plain text only.
link_url string optional A URL to attach to the notification. When clicked, the user is taken to this destination.
type string optional Notification type. One of info, success, or alert. Defaults to info.

Example request

cURL
curl -X POST \ "https://api.flowdesk.io/v1/notifications" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6" \ -H "Content-Type: application/json" \ -d '{ "recipient_ids": ["usr_9aR3bTcU", "usr_4kP1mQsV"], "message": "Product Roadmap Q3 has been updated.", "link_url": "https://app.flowdesk.io/pages/pg_7xK2mNpQ", "type": "info" }'

Response

200 OK 400 Bad Request
JSON
{ "object": "notification", "id": "ntf_5dM2nOpR", "sent_to": 2, "type": "info", "message": "Product Roadmap Q3 has been updated.", "created_at": "2024-08-14T11:15:00Z" }
JSON
{ "error": { "code": "invalid_request", "message": "'recipient_ids' must contain at least one user ID.", "param": "recipient_ids" } }
GET /notifications List notifications for the current user ▼

Query parameters

ParameterTypeRequiredDescription
workspace_id string required The ID of the workspace to retrieve notifications from.
unread boolean optional If true, returns only unread notifications. Defaults to false.
limit integer optional Number of notifications to return. Defaults to 20. Max is 50.

Example request

cURL
curl -X GET \ "https://api.flowdesk.io/v1/notifications?workspace_id=ws_abc123&unread=true" \ -H "Authorization: Bearer fd_live_a1B2c3D4e5F6"

Response

200 OK 401 Unauthorized
JSON
{ "object": "list", "results": [ { "id": "ntf_5dM2nOpR", "object": "notification", "type": "info", "message": "Product Roadmap Q3 has been updated.", "read": false, "created_at": "2024-08-14T11:15:00Z" } ], "has_more": false }
JSON
{ "error": { "code": "unauthorized", "message": "Invalid or missing API key." } }
Errors

Errors & status codes

Flowdesk uses standard HTTP status codes to indicate whether a request succeeded or failed. All error responses return a JSON body with a code and a human-readable message.

200 OK — The request succeeded.
201 Created — A new resource was successfully created.
400 Bad Request — The request was malformed or missing required parameters. Check the param field in the error response for details.
401 Unauthorized — Your API key is invalid, expired, or missing from the request header.
404 Not Found — The requested resource does not exist or has been deleted.
429 Too Many Requests — You have exceeded the rate limit. Wait before retrying. See Rate limits for details.
Rate Limits

Rate limits

To ensure reliability for all users, the Flowdesk API enforces rate limits on all endpoints. Limits are applied per API key on a rolling 60-second window.

Plan Requests / minute Requests / day
Free 60 1,000
Pro 300 10,000
Enterprise Unlimited Unlimited

When you exceed the rate limit, the API returns a 429 status. The response includes a Retry-After header indicating how many seconds to wait before making another request.

✓

Use the X-RateLimit-Remaining response header to track how many requests you have left in the current window before hitting the limit.
